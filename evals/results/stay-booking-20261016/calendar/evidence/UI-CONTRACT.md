## C2 renderer

One export renderCalendarMonths(container,{month,today,draft,focusDate}). Import makeCalendarMonth and shiftCalendarMonth from ./calendar-model.js only. container is an existing HTMLElement. month/today are valid strings,draft is {start,end,error},focusDate optional ISO string. Render exactly the requested month and its next month if supported. Do not mutate caller state or add event listeners,fetch/storage,style attributes or unrelated headers.

Construct actual DOM via createElement,textContent,append and replaceChildren. No innerHTML,outerHTML,insertAdjacentHTML,document.write,HTML interpolation or unsafe property copying. Clear container with replaceChildren. Each month is a section.calendar-month containing a native table with caption.calendar-month-title using model.label. Table uses seven equal logical columns via its later CSS. Each table has a thead with tr and seven th scope=col showing 일,월,화,수,목,금,토; this repeated header is visually hidden by shared CSS while one visible weekday row in the shell owns the visual column labels. tbody has tr/td rows. Leading/trailing blank td have aria-hidden=true and no focusable children; pad each final row to seven cells.

Each real day owns exactly one button type=button class=calendar-day data-date=ISO,data-number=integerstring,disabled=model.disabled. Visible text is the day number via textContent. Accessible aria-label is the unambiguous YYYY년 M월 D일 plus weekday ending 요일; append 체크인 or 체크아웃 for selected endpoints. No emoji or invented icons. A td has data-range=start/end/middle only when appropriate; endpoints also set the button data-selected=start/end. A middle-range button is aria-pressed=true; both endpoints too; all other dates aria-pressed=false. Mark today aria-current=date. Do not omit/preserve invisible duplicate day buttons from prior renders.

Exactly one non-disabled visible date button gets tabindex=0 across the rendered months: prefer focusDate if present/enabled,then selected start if in view/enabled,then first enabled date. All others get tabindex=-1. If both months have no enabled day,no tabindex0. Do not infer a Date instance from an ISO string. Return no required value. Validated data is trusted,but no user text executes as HTML.

## Host shell and C3 interface

Host provides one dialog#date-calendar aria-labelledby=date-calendar-title,with .calendar-shell. Header has h2#date-calendar-title 날짜 선택 and button#calendar-cancel 취소. A month-control row has button#calendar-previous with official ChevronLeft and aria-label 이전 달,and button#calendar-next with official ChevronRight and aria-label 다음 달. These web month controls are a chosen adaptation,not observed native arrows. The visible .calendar-weekdays row has seven labels matching table columns. div#calendar-months owns the scrollable month stack. Footer has p#calendar-selection aria-live=polite,p#calendar-error role=alert and button#calendar-apply 적용하기. No forced separators,flexible-date controls,experience tabs or filler description.

C3 export installDateCalendar({dialog,today}) returns {open,dismiss}. open({start,end},onApply,opener) initializes a private draft from a valid1–28night caller range,or blank when caller values invalid. It does not mutate caller inputs. Sets first shown month to selected start month or today's month. Render via C2. Cancel/Escape closes and returns focus to connected visible opener;dismiss closes/discards without forcing focus. Native close event also clears callback/draft so it cannot apply stale data. Apply only a complete valid range,call onApply once with a fresh {start,end},then close/restore focus. It never submits a booking or writes storage. Reopen reads new supplied values.

Day clicks chooseCalendarDate,render,keep clicked day focused and set error/selection summaries truthfully. Blank summary 체크인 날짜를 선택해 주세요;pending summary 체크아웃 날짜를 선택해 주세요;complete summary uses whole YYYY.M.D dates and countNights 박. Invalid/past days cannot be selected. Previous month cannot precede today's month;next cannot exceed2099-12;both states are real disabled controls. Month navigation does not reset draft and moves focus to a valid date. Bound first month to2000–2099,render one month at2099-12. Calendar today remains an injected date,never browser-local day arithmetic.

On date keys,ArrowLeft/Right move1day,ArrowUp/Down7days,Home/End to Sunday/Saturday;PageUp/Down move one month with day clamped to target month;ShiftPageUp/Down move12months. Clamp below today/above2099-12-31. If destination is outside visible months,update first month to its month. Maintain one roving tabstop and actual focus after re-render. Enter/Space use native button activation. Prevent default only for handled navigation keys. No global key interception or changes to user zoom/scroll. Screen-reader and real-device execution remain unverified until actually performed.
